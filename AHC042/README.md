# AHC042のchokudai search比較

`a02.py`の評価関数と操作生成順（`L`、`R`、`U`、`D`、各方向で0〜19）をC++へ移植し、AHC059と同じ形式で探索結果を測定する。

| ファイル | 用途 |
|---|---|
| `a02.cpp` | 削除なしの二分ヒープ版 |
| `a02-bst.cpp` | 赤黒木版。各層の上位`R`個を保持 |
| `a02-common.hpp` | 両版が共有する盤面、評価、探索本体、経路復元、引数処理 |
| `run-a02.sh` | ヒープ版のコンパイル、全入力の実行、CSV保存 |
| `run-a02-bst.sh` | 赤黒木版のコンパイル、全入力の実行、CSV保存 |
| `average_csv.py` | ケース番号以外の各CSV列の平均を表示 |

状態コンテナと経路木には`../structs/chokudai_search.cpp`を使用する。赤黒木は、この環境のlibstdc++で赤黒木として実装される`std::multiset`を使う。

## 実行

リポジトリのルートから実行する。

```bash
./AHC042/run-a02.sh
./AHC042/run-a02-bst.sh

python3 AHC042/average_csv.py AHC042/out02/a02_results.csv
python3 AHC042/average_csv.py
```

既定の探索条件は1ケースにつき1.9秒・最大1000周回。`in/`の4桁の番号を持つ入力をすべて実行し、最大5ジョブを並列実行する。現在は1000ケースある。

同じ探索回数で比較する場合は、時間制限に達しない値を指定する。`--loops R`の`R`を両版で揃えることで、同評価値の生成順も含めて同じ状態を展開する。赤黒木版は各層で最悪状態を削除し、上位`R`個を残す。

```bash
MAX_JOBS=1 ./AHC042/run-a02.sh --time 60 --loops 100
MAX_JOBS=1 ./AHC042/run-a02-bst.sh --time 60 --loops 100
```

`MAX_JOBS`、`OUTPUT_FILE`、`CXX`の環境変数で、並列数、CSV保存先、C++コンパイラを指定できる。スクリプトの引数は実行するC++プログラムへ渡す。

## 保存される結果

ヒープ版は`out02/`、赤黒木版は`out02-bst/`に保存する。

- `a02_results.csv` / `a02-bst_results.csv`：全ケースの測定結果。ケース番号順。
- `out02_0000.txt` / `out02-bst_0000.txt`：出力した操作列。
- `out02_0000.stderr.txt` / `out02-bst_0000.stderr.txt`：標準エラー出力。

CSVの列はAHC059と共通。

| 列 | 意味 |
|---|---|
| `case_number` | 入力ファイルの番号 |
| `peak_memory_kb` | `/usr/bin/time`の`%M`で測った最大RSS（KiB） |
| `total_path_length` | 出力した操作回数。標準エラーの`Total path length` |
| `final_layer_visits` | 最終層まで進んだ周回数。標準エラーの`Final layer visits` |

## AHC042における探索の終了と到達回数

[公式問題](https://atcoder.jp/contests/ahc042/tasks/ahc042_a)に従い、操作数の上限は1600回とする。福をすべて残し、鬼をすべて除去した状態を解として記録する。

`a02.py`と同様、長さ`L`の解が見つかった後は、`L-1`手以下の解を探す。各周回で解を発見した場合、またはその時点の探索上限層まで子状態を生成した場合に、`final_layer_visits`を1増やす。途中で時間制限に達した周回は、上限層にも解にも到達していなければ数えない。生成した子状態の個数や、完全な解を発見した個数とは異なる。

時間切れで完全な解が見つからない場合は、生成済み状態のうち評価値が最良の経路を出力する。既存Python版では探索済みの状態が層の先頭に残るため、C++版では状態をキューから取り出し、次の未探索状態へ進む構造にしている。

検証では`--time 60 --loops 3`で1000ケースを実行し、両版の操作列・操作回数・最終層到達回数が一致することと、福を落とさず鬼をすべて除去できることを確認した。保存済みCSVはこの条件で得た結果。
